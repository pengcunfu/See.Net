# See.Net 安装和故障排除指南

## 推荐安装方式：自包含版本

直接运行发布文件夹中的 See.exe 即可，无需任何证书配置。

1. 找到自包含发布文件夹：
   `
   D:\Projects\DevTools\See.Net\See.Net\bin\Release\net10.0-windows\win-x64\publish
   `

2. 直接运行 See.exe：
   - 双击 See.exe
   - 或者使用项目根目录的"启动See.Net.bat"脚本

3. 创建快捷方式：
   - 右键点击 See.exe
   - 选择"发送到" -> "桌面快捷方式"

## 系统要求

- Windows 10 或更高版本 (64位)
- 4GB 或更多内存
- 500MB 可用磁盘空间
- WebView2 运行时（通常已预装）

### 常见问题

**Q: 自包含版本会占用更多空间吗？**
A: 大小约 184MB，包含必要的运行时文件。

**Q: 我可以在多台计算机上使用同一个自包含版本吗？**
A: 可以，只需将整个 publish 文件夹复制到目标计算机即可运行。

**Q: 如何卸载？**
A: 直接删除整个文件夹即可，不会在系统中留下残留。

### 技术支持

如遇到其他问题，请检查：
1. Windows Defender 或其他安全软件是否阻止了程序运行
2. 确保下载的文件完整，没有损坏
3. 检查 Windows 更新，确保系统为最新版本
4. 如果是网络问题，可以尝试离线安装

### 文件清单

**自包含版本包含：**
- See.exe (主程序)
- DLL 文件（运行时和依赖库）
- webassets 文件夹（Office 和 Markdown 预览资源）
- 多语言支持文件夹
- README.md（用户手册）
